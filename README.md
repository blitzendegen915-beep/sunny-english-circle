# Sunny English Circle — HP試作（公開用ビルド）

0〜2歳児と保護者の親子英語サークル「Sunny English Circle」のホームページ試作。
**クライアント未承認の下書き**であり、確定サイトではない。

## このリポジトリの扱い

- 全ページに `<meta name="robots" content="noindex, nofollow">` を付けている（検索結果に出さないため）
- `images/` の写真のうち、人物が写る2枚（`lesson-song.jpg` / `lesson-play.jpg`）は
  **顔をぼかした加工版**。加工前の元画像はこのリポジトリに入れていない
- クライアントのヒアリング情報（社外秘）はこのリポジトリに含めない

## 未確定・差し替え待ちの項目

HTML内に `<!-- 差し替え: ... -->` として記載してある。

1. 申込用Googleフォームの**回答用**URL（Instagramに載っているのは編集用URLなので使わない）
2. InstagramアカウントURL
3. 連絡先メールアドレスの掲載可否
4. 開催日時（曜日・時間・所要時間）
5. 会場の詳しい住所を載せるか

加えて `about.html` に `<!-- 要確認: ... -->` が2件ある（制作側の推測が入った文）。

## 公開前に必要な確認

- 写真に写っている**子どもの保護者と講師本人の掲載承認**
- 掲載内容全体のクライアント承認

## ファイル構成

```
index.html      トップ（写真4枚のクロスフェード）
about.html      サークルについて／レッスンの内容
schedule.html   開催エリア・会場／開催日時
join.html       参加費／お申し込み
images/         写真4点
.nojekyll       GitHub PagesのJekyll処理を無効化
```

ビルド不要の静的HTML。外部CDN・Webフォント・外部画像への通信は発生しない。
